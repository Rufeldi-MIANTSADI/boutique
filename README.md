Ce programme est une application console développée en C# permettant de calculer le prix total TTC d’un article dans une boutique.

 Fonctionnement
- L’utilisateur saisit :
  - le nom de l’article
  - le prix unitaire
  - la quantité
- Le programme calcule :
  - le prix total HT
  - le prix total TTC avec une TVA de 18%

- Le résultat est ensuite affiché à l’écran.
